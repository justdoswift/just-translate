# Just Translate

使用自己的 DeepSeek 或 OpenAI 兼容 API，一键双语翻译当前网页。没有划词翻译、悬浮词典、账号系统或中转服务器。API 费用直接由所选模型服务商收取。

## 在 Chrome 中安装

要求：Chrome 120+；从源码构建需要 Node.js 22.12+ 和 npm。

```sh
git clone https://github.com/justdoswift/just-translate.git
cd just-translate
npm ci
npm run build
```

1. 打开 `chrome://extensions`，开启右上角的「开发者模式」。
2. 点击「加载已解压的扩展程序」。
3. 选择本项目的 `.output/chrome-mv3` 目录，不是项目根目录。
4. 将 Just Translate 固定到工具栏。
5. 右键插件图标，选择「选项」，填写自己的 API Key。
6. 点击「保存并测试」，允许访问模型 API 域名；成功后配置自动保存。测试会产生少量 API 用量。
7. 回到网页，按 `Option+Q`（Windows/Linux 为 `Alt+Q`）或点击插件图标开始翻译。再次触发恢复原文。

更新源码并重新构建后，保持 Chrome「开发者模式」开启，在 `chrome://extensions` 刷新插件，再刷新待翻译网页。

快捷键使用独立的「切换原文 / 译文」命令。设置页显示 Chrome 实际绑定值；点击「翻译快捷键」可打开 `chrome://extensions/shortcuts`。若显示「未设置」或其他按键，在 Just Translate 的「切换原文 / 译文」一栏设置 `Option+Q`。快捷键仅在 Chrome 获得焦点时生效。

## 模型配置

| 配置         | DeepSeek 预设              | 自定义 OpenAI 兼容服务                             |
| ------------ | -------------------------- | -------------------------------------------------- |
| API 基础地址 | `https://api.deepseek.com` | 例如 `https://your-provider.example/v1`            |
| 模型名称     | `deepseek-flash`           | 服务商实际支持的模型 ID                            |
| API Key      | 自己的 DeepSeek Key        | 自己的服务商 Key                                   |
| JSON 模式    | 开启                       | 默认关闭；确认接口支持后再开启                     |
| 关闭思考模式 | 开启                       | 默认关闭；只在支持 `thinking.type=disabled` 时开启 |

基础地址后会追加 `/chat/completions`，不要自行填写这个后缀。远程接口必须使用 HTTPS；允许 `localhost`、`127.0.0.1` 和 `[::1]` 的本机 HTTP 接口。本机服务若不校验密钥，可填入无敏感信息的占位值。

兼容服务需支持 Chat Completions 的 `messages`、`max_tokens`、`stream: false`，并在 `choices[0].message.content` 返回遵循提示的 JSON。仅提供 Responses API、Anthropic API 或无法稳定返回结构化结果的服务不适用。

DeepSeek 默认输入/输出估算单价为每百万 token $0.30 / $1.20，按官方文档的高峰、输入缓存未命中费率设置。自定义接口默认单价为 0，**使用费用上限前必须填写实际单价**。可在「计费估算与单页限制」中修改。

模型与价格会变动，以 [DeepSeek 官方模型与定价](https://api-docs.deepseek.com/quick_start/pricing) 为准；本插件不自动拉取价格。更换服务商或 API 域名会清空表单中的密钥，避免误发给另一个服务商。

## 阅读行为

- 点击后先翻译可视区域，再处理已经加载的其他正文。
- 新增评论、无限滚动、展开内容和原段落修改，会自动触发增量翻译。
- 原文保留，译文显示在段落下方；不替换原链接、表单或事件处理器。
- 行数截断只在翻译期间解除；原有样式和按钮事件在恢复原文后保留。
- 代码块、输入框、可编辑区域、导航控件和明确禁止翻译的节点会跳过。段落内的行内代码保持原样。
- 长段落按句子或词边界分块。模型返回的段落 ID、完整性及代码占位符必须通过校验。
- 页面修改后，过期响应不会写入新内容。停止后，迟到响应不会重新插入译文。
- 后台被 Chrome 休眠后，原页面会话可以继续补译。结果未确认的已发送请求不会自动重发。
- 普通页内锚点跳转保留翻译。刷新、真实页面导航、SPA 路由或明确文章标识变化后停止，需要再次点击开启。
- 没有文章标识、没有路由变化的正文容器替换，按当前页面的新加载内容处理，不误判为换页。
- 每个标签页独立开关。失败段落显示错误及「重试此段」，不清空其他已成功译文。

工具栏徽标：「译」表示处理中；「✓」表示当前内容已处理并等待新内容；「!」表示部分失败或需要检查配置。

## 用量、缓存与隐私

- 只在手动开启的网页上工作，不自动读取所有浏览记录。
- 通过 `activeTab` 临时授权访问当前页面，API 域名授权在保存或测试连接时申请。
- 开启后，会把所提取的正文和附近标题上下文发送给你配置的服务商，不发送整页 HTML。不要在含有私密资料的页面随意开启。
- API Key 仅在扩展受信任上下文中使用，不交给网页或内容脚本，不使用 Chrome 同步存储。
- 默认密钥仅存于 `chrome.storage.session`，关闭浏览器或重新加载扩展后需要重填。勾选「在本机记住密钥」后写入 `chrome.storage.local`；这不是加密保险箱。
- 默认译文只使用会话缓存。可选择本机持久缓存，默认保留 7 天；缓存最多 400 段且最多约 2 MB，达到限制时淘汰旧条目。
- 缓存区分原文、上下文、目标语言、模型、API 地址和账号。清除缓存不会删除模型设置或密钥。
- 默认月度估算上限为 $5，单页 token 上限为 50000；设置为 0 表示取消相应限制。
- 调度器在发送前预留预算，避免多个标签页同时透支。预算不足时仍可展示缓存命中的译文。
- 用量只覆盖本插件发出的请求。费用是估算值，不是服务商账单；缺失 usage 或请求结果未知时采用保守估算。
- 显式 429 最多自动重试一次；超时、断线、未知结果不自动重发，避免重复计费。手动重试仍可能产生新的费用。
- 模型结果只作为文本显示，不执行模型返回的 HTML 或脚本。

## 支持边界

当前支持普通网页顶层文档中的可读文本，不处理 PDF、图片 OCR、Canvas、iframe 内文、封闭 Shadow DOM、Chrome 内部页面或禁止扩展注入的页面。

翻译筛选以正文阅读为目标，不承诺翻译每个菜单、按钮或表单标签。语言跳过采用保守判断；语言标记不准确的页面可能仍发送已是目标语言的文本。

依赖 DOM 变更、展开事件及滚动识别新内容。仅靠持续动画改变可见性、且没有这些事件的内容，不使用无限轮询追踪。虚拟列表仍由网站决定节点保留范围。

模型译文质量取决于所选服务商。本地协议测试不代表对所有网站、所有模型或付费 DeepSeek 质量的保证。

## 开发与验证

```sh
npm run dev
npm run typecheck
npm test
npm run build
```

`npm run dev` 使用 WXT 开发模式；安装交付包使用生产构建目录。

浏览器回归使用独立的临时 Chrome 配置，不读取个人浏览器数据；本机测试 API 的权限由测试配置预先授予：

```sh
npx playwright install chromium
npm run test:chrome
```

目录职责：

- `entrypoints/background.ts`：工具栏开关、消息权限、文档会话生命周期。
- `src/background/`：配置隔离、模型调用、队列、预算预留、请求记账与缓存。
- `src/content/`：正文提取、动态观察、分块、过期校验与双语渲染。
- `entrypoints/options/`：模型、语言、缓存及用量设置。
- `tests/`：接口错误、预算并发、请求恢复、缓存失效及导航回归测试。

回归覆盖权限边界、保存并测试后的实际翻译、增量内容、行数截断、按钮事件保留、被移除译文的恢复、首屏与新增段落的原位 loading、停止后不再发请求，以及失败测试不覆盖已保存配置。浏览器测试检查实际快捷键注册，再通过 Chrome 工具栏动作验证共用启停流程；这不等于 macOS 原生按键投递测试。

自动化回归使用本机受控 OpenAI 兼容测试服务。经所有者授权，另使用真实 DeepSeek API 验证了连接、段落翻译、行内代码保留和新增内容补译；密钥仅用于隔离浏览器会话，不进入源码或 Git。不同服务商仍需在设置页测试自己的连接。

0.1.2 的 Substack 检查使用真实 DeepSeek API，覆盖首页正文、卡片可见性与翻译完成状态。0.1.3 的段落 loading 使用受控延迟 API，在真实 Chrome 中检查位置、译文替换、动态内容、失败重试、停止清除及明暗模式。网站内容持续变化，单次检查不代表所有登录态和所有卡片类型都已覆盖。
